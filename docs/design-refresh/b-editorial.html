Fail Eagerly

Antonio Villanueva1 min readLiving — current, not complete

The sooner I find out I'm wrong, the sooner I can learn what's right. Failure is not a penalty — it's a high-value data point, and it's cheap if you catch it early.

This isn't the Silicon Valley "fail fast" that means shipping broken products. It's about intellectual speed. The faster you falsify a bad idea, the faster you reach a real one.

The danger is not failure — it's the slow rot of unchallenged certainty.

This belief shapes how I build: prototypes over plans, tests over assurances, visible interfaces over hidden magic. If the system is going to fail, it should fail where I can see it.

These essays are personal frameworks, not settled claims. They change as I do.
